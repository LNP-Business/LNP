# Objections · nommer les résistances sans marqueur (OB-1)

Un inventaire du code a déjà signalé les tours du prospect qui contiennent un marqueur typique de résistance. Ta tâche :
lister les autres tours PROSPECT ou OTHER de l'extrait qui expriment une résistance sans contenir de marqueur de la liste.

Une résistance est un passage où le prospect (ou un codécideur étiqueté OTHER) exprime :
- une objection : un doute sur l'offre, son prix ou ses conditions, l'entreprise, le commercial, ou une ressource qui lui
  manque (du temps, de l'argent, l'accord d'un codécideur) ;
- une anxiété : un doute sur lui-même (ne pas y arriver, ne pas tenir) ou sur sa décision (se tromper, se faire avoir) ;
- une inertie : un attachement au présent, ou un report sans raison externe.

Ne jamais nommer (OB-2) : une demande d'information sans réserve dans le même tour ; un délai avec une raison externe et
vérifiable (un déménagement, une fin de contrat) ; un fait neutre du circuit de décision (« c'est mon mari qui gère
l'argent ») ; une acceptation sous condition (« si je peux payer tous les mois, alors oui »).
Ne jamais nommer un tour listé sous DÉJÀ SIGNALÉS.

"quote" : les mots exacts de ce tour qui expriment la résistance.
JSON: {"nominations": [{"turn": "T051", "quote": "exact words of that turn expressing the resistance"}]}
Une liste vide est une réponse valide.
