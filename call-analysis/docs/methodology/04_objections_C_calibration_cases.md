# Annex B · Calibration set for objections

This set holds 30 real cases taken from Valentino's sales calls (Interior Academy, June–October 2026), drawn from 23 different calls. Each excerpt is an exact quote from the call transcript, labelled with its speaker and turn; the label in the first column gives the turn where the case starts. The expected verdicts are proposals made by applying Annex A. Two certified annotators must confirm them, each working blind, before the set is used as gold. Cases marked **Boundary** sit on a frontier between two rules (21 of 30). The set is never used as examples in a prompt. It is used to train annotators and to test that a new rules version does not regress.
