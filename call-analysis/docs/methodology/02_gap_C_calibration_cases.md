# Annex B · Calibration set for the gap

This annex holds 32 real cases taken from Valentino's sales calls (Interior Academy, June to October 2026): 12 passage-level cases, 8 validation cases, 10 call-level gate verdicts and 2 gap-formula cases, spread over 22 calls. Every excerpt is an exact quote from the call transcript, labelled with its call number and turn. The expected verdicts are proposals obtained by applying Annex A; they must be confirmed by two certified annotators working blind, with disagreements settled by the arbiter, before the set is used as gold. The set is never used as examples in a prompt; it serves to train annotators and as the non-regression set of the machine. **Version 1.2:** every expected verdict has been re-checked against the verbatim rules (GB-22 to GB-27); the key expression of each component is given with its source turn. Cases marked "Frontier" or "uncovered_case" are where the current rules leave room for doubt.
