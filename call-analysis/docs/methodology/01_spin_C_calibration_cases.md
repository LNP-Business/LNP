# Annex B · Calibration set for SPIN discovery

This set holds 30 real cases taken from Valentino's sales calls (The Interior Academy, June to October 2026), spread over 17 calls, 21 of them boundary cases. Each excerpt is an exact quote from the call transcript, checked by script against the turn it cites. The expected verdicts are proposed by applying the rules of this methodology (§2, §3, §4 and Annex A); they must be confirmed by two certified annotators working blind, with disagreements arbitrated, before the set is used as gold. The cases are never used as examples in the prompts. They serve to train annotators and as a non-regression set: every change to the rules, prompts or model is re-run against them. Turn numbers refer to the compact transcript of each call.
