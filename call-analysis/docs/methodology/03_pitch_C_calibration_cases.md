# Annex B · Calibration set for the pitch

This set holds 37 real cases taken from Valentino's sales calls (Interior Academy, June to October 2026), spread over 21 calls, 17 of them boundary cases. Each excerpt is quoted exactly from the compact transcript (speaker and turn given; turns as numbered in that transcript). The expected verdicts are proposals made by applying Annex A. Two certified annotators, working blind, must confirm them before the set is used as gold; where they disagree, the case goes to the arbiter. The set is never used as examples in prompts. It is used to train annotators and to run non-regression tests whenever the rules or prompts change. Cases marked "Boundary" in the verdict column sit at the edge of a rule. Where the rules are silent or point both ways, the verdict says so and the case goes to the arbiter as `uncovered_case` until a rule is written.

## B5. Category of P (version 2.0)
