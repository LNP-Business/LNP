Page method

Roadmap

1What this page is for

Where key results are built, run and closed. Each key result follows the same template: definition, 3 to 5 initiatives, milestones, the task roadmap, risks, a weekly check-in and the closing score. Anyone can add tasks here, like in a project manager.

2How it makes everyone more efficient

  • Outcomes, not activity. A key result is achieved only if its metric moves, whatever the number of tasks done.
  • Every task serves a bet. Tasks hang under an initiative, and each initiative states what it should move.
  • Early warning. The leading indicator and the weekly confidence show trouble weeks before the result does.

3How to use it

  1. Pick a key result on the left, or create one with “+ New key result”.
  2. Definition: set the metric, baseline, target, data source and leading indicator.
  3. Initiatives: write 3 to 5 levers as “if… then…”, with their expected contribution.
  4. Milestones: one concrete deliverable per step; W6 is the mid-point to keep or pivot initiatives.
  5. Task roadmap: add tasks of 8 h max, tied to an initiative, with an owner and weeks.
  6. Every week, the owner posts the check-in. At W12, close the key result with its score.
