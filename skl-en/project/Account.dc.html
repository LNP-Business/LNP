Qui utilise LNP ici

Les écrans montrent le travail de la personne choisie ici : ses tâches, ses alertes et ses suivis.

Connexion et équipe

Dans la version web de LNP, c’est ici que vous voyez le compte avec lequel vous êtes connecté, que vous vous déconnectez et, si vous êtes administrateur, que vous invitez l’équipe et choisissez les rôles.

Page method

Compte

1À quoi sert cette page

Qui utilise LNP ici : la personne dont les écrans montrent le travail, le compte connecté et l’équipe.

2En quoi elle aide

  • Le menu ne garde que les écrans ; votre compte et l’équipe sont réunis au même endroit.
  • Les administrateurs invitent des personnes et choisissent leur rôle sans quitter les Paramètres.

3Comment l’utiliser

  1. Vous êtes : choisissez votre nom pour que les écrans montrent votre propre travail.
  2. Dans la version web, Se déconnecter met fin à votre session sur ce navigateur.
  3. Administrateurs : Accès de l’équipe invite quelqu’un (envoyez-lui le lien obtenu), change un rôle, donne un lien de réinitialisation ou retire une personne. Les écrans que chacun peut ouvrir se règlent dans l’onglet Accès.
